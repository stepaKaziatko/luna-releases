# Luna — архив сборок

**Luna переехала в [stepaKaziatko/luna-assistant](https://github.com/stepaKaziatko/luna-assistant)** — там открытый исходный код (MIT), новые релизы, руководство пользователя и issues. Этот репозиторий — архив сборок v0.2.0–v1.0.0, новых релизов здесь не будет.

## Установка

```sh
curl -fsSL https://raw.githubusercontent.com/stepaKaziatko/luna-assistant/main/install.sh | sh
```

Прежняя команда с этим адресом тоже работает: [install.sh](install.sh) отсюда ставит последний релиз из `luna-assistant`, а прежние версии (`LUNA_VERSION=v0.7.0`, вплоть до `v1.0.0`) — из архива этого репозитория.

- Руководство пользователя — первый запуск, подключение агентов, хоткеи, удаление и данные: [docs/USER-GUIDE.md](https://github.com/stepaKaziatko/luna-assistant/blob/main/docs/USER-GUIDE.md).
- Релизы: [luna-assistant/releases](https://github.com/stepaKaziatko/luna-assistant/releases).
- Ошибки и предложения: [luna-assistant/issues](https://github.com/stepaKaziatko/luna-assistant/issues).
