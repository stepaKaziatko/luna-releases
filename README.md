# Luna

Luna живёт в вырезе MacBook (на мониторе без выреза — в полоске у верхнего края) и присматривает за сессиями ИИ-агентов: Claude Code, Codex, Gemini CLI, Cursor, Copilot CLI, OpenCode, Amp, Hermes и других. Из острова можно разрешить или отклонить запрос агента, ответить на его вопрос, перейти к его окну, поговорить с моделью, бросить файл, следить за GitHub, Vercel, Stripe и другими сервисами — не отрываясь от работы. В острове — маленький персонаж, который дышит, моргает и следит за курсором.

В этом репозитории лежат готовые сборки. Исходный код закрыт.

## Что умеет

- **Страница «Агенты»** — она же домашняя: по плитке на каждую сессию агента с аватаром, проектом, приложением, где идёт сессия, и последними шагами. Кто ждёт вашего разрешения или ответа — первый и горит оранжевым, закончивший ход — зелёным, ошибка — красным.
- **Страница агента:** одна сессия подробно, последние 20 шагов. Если агент ждёт вас — здесь же его вопрос с вариантами ответа или запрос разрешения с кнопками Allow / Deny / Always. Ничего не разрешается без вашего клика.
- **«Перейти к агенту»** открывает окно, где идёт сессия: в VS Code и родственных редакторах — папку проекта и вкладку Claude Code, в Terminal и iTerm2 — именно ту вкладку, в других терминалах — само приложение, а если неизвестно, где запущен агент, — папку проекта в Finder.
- **Агенты на челке.** Свёрнутый остров показывает маленькую Luna на каждую сессию, где есть новости. Задержите курсор на челке — вырастет блок с самыми срочными агентами; приложение, в котором вы работаете, остаётся активным.
- **Сессии в «таблетках»:** что агент читает, правит и запускает, шаг за шагом; правки файлов с `+N −M`, по клику — полный diff.
- **«Активные вкладки»** — отдельная страница с рабочим местом, ИИ для чата, сервисами и планом Claude и Codex. Когда подключён GitHub, в шапке появляется своя вкладка: мои PR с CI и ревью, что ждёт вашего ревью, CI основной ветки.
- **Управление с клавиатуры:** `⌃⌥S` открывает «Агенты», `⌃⌥P` — «Активные вкладки», дальше стрелки, `↩`, `⌫`, `⎋`; `⌘⎋` сворачивает раскрытую шторку из любого приложения. Подробно — в разделе [Хоткеи](#хоткеи).
- **Чат** с Claude, Gemini, OpenAI или локальной моделью (Ollama, LM Studio) по своему ключу — или по вашей подписке через установленный Claude Code, без ключа API. Диктовка в чат; лимиты плана Claude и Codex в шапке.
- **Интеграции:** GitHub, Vercel, Stripe, Resend, n8n, Notion, Cal.com, Apple Music, Spotify, Apple Mail, курсы криптовалют.
- **Файл на остров** — персонаж «проглатывает» его, дальше вопрос по файлу или письмо.
- **«OK Luna»** — голосовое управление: речь распознаётся на Mac, в Anthropic уходит только текст.
- **Еженедельный отчёт** по понедельникам: время, сессии, файлы, строки, команды.

Интерфейс на десяти языках, без телеметрии, ключи хранятся в Связке ключей (Keychain).

## Требования к системе

- **macOS 15 или новее.** На более старой системе скрипт установки откажет.
- **Apple Silicon или Intel** — одно универсальное приложение (arm64 и x86_64 в одном бандле).
- **Экран.** На MacBook с вырезом остров встаёт в вырез; на Mac без выреза и на внешних мониторах — полоской у верхнего края. На каком экране показывать остров, выбирается в Настройки → Основные (Display): экран с вырезом, главный экран, экран под курсором или конкретный монитор.
- **Для наблюдения за агентами** — сам CLI агента (Claude Code, Codex, Gemini CLI…) и хуки Luna в его настройках (см. [Подключение агентов](#подключение-агентов)). Хук запускает системный `python3`, поэтому нужны **Command Line Tools**: `xcode-select --install`. Без них хук молча ничего не передаёт, и агенты в острове не появляются.
- **Чтобы отвечать на вопросы Claude Code из острова** — Claude Code 2.1.85 или новее.
- **Для чата** — ключ провайдера (Claude, Gemini, OpenAI), локальная модель (Ollama, LM Studio) или установленный Claude Code, в который вы вошли по подписке. Чата через Codex пока нет. Для «OK Luna» с Claude в роли мозга нужен ключ Anthropic API.
- **Сеть** — для установки, чата и подключённых сервисов. Других обращений в сеть и телеметрии нет.

## Установка

```sh
curl -fsSL https://raw.githubusercontent.com/stepaKaziatko/luna-releases/main/install.sh | sh
```

Скрипт качает последний релиз, сверяет контрольную сумму и кладёт `Luna.app` в «Программы».

| Переменная | Что делает |
|---|---|
| `LUNA_VERSION=v1.0.0` | поставить конкретный релиз вместо последнего |
| `LUNA_INSTALL_DIR=~/Apps` | куда класть; по умолчанию `/Applications`, если он доступен на запись, иначе `~/Applications` |

### Что лежит в релизе

В каждом релизе два файла: `Luna-<версия>-macos-universal.zip` с `Luna.app` (arm64 и x86_64 в одном бандле) и `checksums.txt` с SHA-256. Ядра и сборок под другие системы нет.

### Вручную

Скачайте `Luna-<версия>-macos-universal.zip` со [страницы релиза](https://github.com/stepaKaziatko/luna-releases/releases/latest), распакуйте и перенесите `Luna.app` в «Программы».

Сборка подписана ad-hoc и не нотаризована Apple, поэтому скачанную браузером копию macOS с первого раза не откроет. Откройте её способом Apple: попробуйте запустить Luna, затем зайдите в Системные настройки → Конфиденциальность и безопасность и нажмите «Всё равно открыть» рядом с сообщением о Luna. Это нужно один раз.

Скрипт установки снимает карантин с поставленного приложения сам, поэтому после него этот шаг не нужен.

### Обновление

Luna обновляется той же командой установки; встроенной проверки обновлений в приложении нет. Запущенную Luna скрипт закроет перед заменой — после этого запустите её снова. После обновления macOS может заново спросить разрешения.

Версия 1.0.0 — другое приложение, а не обновление 0.7.x: задачи, историю и настройки прежних версий она не переносит и не удаляет, прежние хоткеи 0.x не работают. Установка 1.0.0 заменяет `Luna.app` в «Программах».

## Первый запуск

```sh
open /Applications/Luna.app
```

У верхнего края экрана появится остров — в вырезе MacBook или полоской по центру на мониторе без выреза; в строке меню — значок Luna с меню: «Открыть Luna», «Итоги недели», «Настройки…», «Выход». Значка в Dock у Luna нет. Чтобы Luna запускалась сама, включите «Запускать при старте Mac» в Настройки → Основные.

`⌃⌥S` открывает страницу «Агенты». Пока агенты не подключены, на ней подсказка, как это сделать.

## Подключение агентов

Агенты появляются в острове только после установки хуков: страница «Агенты» строится из событий, которые присылает хук. Хуки ставятся вручную, по одному CLI:

1. Настройки → Агенты → блок нужного CLI → «Установить хуки» (у OpenCode, Amp и Hermes — «Установить плагин»).
2. Luna показывает, что именно запишет, — просмотрите и нажмите «Подтвердить и записать». Без подтверждения файл не меняется.
3. Начните новую сессию агента (Gemini CLI, Copilot CLI, OpenCode, Amp, Muse Code, Antigravity — перезапустите). Codex сначала попросит подтвердить хуки у себя: откройте Codex и выполните `/hooks`.

Там же кнопка «Удалить» убирает хуки Luna из настроек CLI. Перед записью существующего файла Luna кладёт рядом копию `<имя файла>.bak-<дата>`.

| CLI | Что меняет Luna |
|---|---|
| Claude Code | `~/.claude/settings.json` |
| Codex | `~/.codex/hooks.json` |
| Gemini CLI | `~/.gemini/settings.json` |
| Antigravity | `~/.gemini/config/hooks.json` |
| GitHub Copilot CLI | `~/.copilot/hooks/luna.json` |
| Muse Code | `~/.config/muse/settings.json` |
| OpenCode | `~/.config/opencode/plugins/luna.js` |
| Amp | `~/.config/amp/plugins/luna.ts` |
| Hermes | `~/.hermes/plugins/luna`; запросы подтверждения в острове — по отдельному переключателю, он меняет `~/.hermes/config.yaml` |

Сам хук — `luna-hook` и `luna-hook.py` в `~/Library/Application Support/Luna`; Luna кладёт их туда сама при запуске.

Ещё два необязательных пункта в Настройки → Агенты:

- **Вопросы и разрешения терминальных сессий в острове** — переключатель «Answer questions and permissions from terminal sessions in the notch». Выключен — сессии в Terminal, iTerm, Warp видны в острове, но спрашивают в терминале. Включён — сначала спрашивает остров, а терминал ждёт ответа до 2 минут.
- **Лимиты плана Claude в шапке** — блок «Использование плана» → «Установить ретранслятор». Добавляет строку состояния в `~/.claude/settings.json` (если своя строка состояния уже есть, она продолжает работать) и тоже показывает изменения перед записью; убирается кнопкой «Удалить ретранслятор». Только для планов Pro и Max.

## Хоткеи

Глобальные сочетания работают из любого приложения; посмотреть и поменять их можно в Настройки → Горячие клавиши.

| Действие | Хоткей |
|---|---|
| Открыть чат | `⌃⌥Space` |
| Открыть «Агенты» (повторное нажатие закрывает остров) | `⌃⌥S` |
| Открыть «Активные вкладки» (повторное нажатие закрывает остров) | `⌃⌥P` |
| К ожидающему запросу агента | `⌃⌥A` |
| В терминал агента | `⌃⌥T` |
| Прикрепить переднее окно как контекст | `⌃⌥W` |
| Следующая / предыдущая вкладка | `⌃⌥]` / `⌃⌥[` |
| Включить / выключить звук | `⌃⌥M` |
| Персонаж на рабочий стол и обратно | `⌃⌥D` |
| Гардероб | `⌃⌥G` |
| Свернуть раскрытую шторку (пока шторка свёрнута, сочетание свободно для других приложений) | `⌘⎋` |

Ещё два сочетания по умолчанию выключены и включаются в настройках: `⌘⇧N` — открыть и закрыть остров, `⌃⌥V` — говорить с Luna без слова-активатора.

### Клавиши острова

После хоткея страницы (или клика по острову) клавиатура у острова, а приложение, в котором вы работали, остаётся активным. `?` в острове показывает клавиши текущей страницы.

| Где | Клавиши | Что делают |
|---|---|---|
| Любая страница | `⎋` | закрыть остров (если он не закреплён) |
| Любая страница | `?` | показать / скрыть клавиши страницы |
| «Агенты» | стрелки | выбрать агента |
| «Агенты» | `↩` | открыть страницу выбранного агента |
| «Агенты», страница агента | `⌘↩` | перейти к окну агента |
| Страница агента | `⌫` | назад к списку агентов |
| «Активные вкладки», GitHub | `⌫` | назад к «Агентам» |
| «Активные вкладки» | `←` / `→`, `↑` / `↓`, `↩` | вкладка, элемент списка, открыть выбранное |
| GitHub | стрелки, `↩` | выбрать pull request или репозиторий, открыть на GitHub |
| Запрос разрешения | `←` / `→`, затем `↩` | выбрать «Запретить», «Разрешить» или «Всегда», затем отправить |
| Вопрос агента | стрелки или `1–4`, затем `↩` | выбрать вариант, затем ответить |
| Вопрос с несколькими ответами | `Space` | отметить / снять вариант |

Ответ на запрос и вопрос — всегда в два шага: стрелка или цифра только выбирают, отправляет `↩`. Работают и прежние клавиши острова: `⌘←` / `⌘→` и `⌘1–9` — вкладки, `⌘↑` / `⌘↓` — элементы списка, `⌘,` — настройки, `⌘P` — закрепить остров.

## Разрешения macOS

Luna просит их по мере надобности, а не при старте, и без них работает в урезанном виде. После обновления macOS может спросить разрешения заново.

| Разрешение | Зачем |
|---|---|
| Автоматизация | перейти к вкладке агента в Terminal и iTerm2 (спрашивается при первом нажатии «Перейти к агенту»), управлять Музыкой и Spotify, отправить письмо через Mail |
| Универсальный доступ | заголовок активного окна, когда его прикрепляют как контекст |
| Микрофон и распознавание речи | диктовка в чат и «OK Luna» |
| Контакты | адрес получателя, когда письмо просят голосом |

## Проверка файлов

К каждому релизу приложен `checksums.txt` с SHA-256 всех файлов:

```sh
shasum -a 256 -c checksums.txt --ignore-missing
```

Каждый выложенный релиз проверяет workflow «Verify release»: ставит сборку скриптом установки, сверяет подпись и архитектуры, запускает приложение и убеждается, что оно завершается по сигналу.

## Удаление и данные

1. Снимите хуки: Настройки → Агенты → «Удалить» у каждого CLI, где они стоят, и «Удалить ретранслятор», если ставили его. Иначе в настройках CLI останется команда, которая вызывает уже несуществующий `luna-hook`.
2. Выключите «Запускать при старте Mac» в Настройки → Основные, если включали.
3. Выйдите из Luna (значок в строке меню → «Выход») и удалите `Luna.app` из «Программ».

Вместе с приложением данные не удаляются. Где они лежат — удалите сами то, что не нужно:

| Что | Где |
|---|---|
| Хук, сокет, итоги недели (`recap.json`), папка чата, свои звуки (там же — данные версий 0.x) | `~/Library/Application Support/Luna` |
| Журналы | `~/Library/Logs/Luna` |
| Настройки | `defaults`, домен `dev.luna.Luna` |
| Ключи сервисов и моделей | Связка ключей, служба `dev.luna.Luna` |
| Переписка чата через Claude Code | у самого Claude Code: `~/.claude/projects`, папка `…Luna-chat` |
| Резервные копии настроек CLI | рядом с файлами из таблицы [Подключение агентов](#подключение-агентов), `*.bak-<дата>` |
