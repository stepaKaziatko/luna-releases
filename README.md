# Luna

Десктопный ИИ-ассистент для macOS. Нажали хоткей в любом приложении, написали короткий запрос — задача выполняется в фоне, а результат приходит карточкой. Luna не забирает фокус: вы продолжаете работать там, где были.

Вместе с запросом Luna передаёт то, что у вас на экране: приложение, адрес и заголовок страницы браузера, выделенный текст. «Дай сводку по этому репозиторию» над страницей GitHub работает без копирования ссылок.

В этом репозитории лежат готовые сборки. Исходный код закрыт.

## Установка

Нужны macOS 14 или новее, [Node.js](https://nodejs.org) 22.18+ и [Claude Code](https://claude.com/claude-code) с выполненным входом — задачи выполняет он.

```sh
curl -fsSL https://raw.githubusercontent.com/stepaKaziatko/luna-releases/main/install.sh | sh
```

Скрипт качает последний релиз, сверяет контрольную сумму и кладёт `Luna.app` в «Программы». Сборка одна на Apple Silicon и Intel. Этой же командой Luna обновляется.

| Переменная | Что делает |
|---|---|
| `LUNA_VERSION=v0.2.0` | поставить конкретный релиз вместо последнего |
| `LUNA_INSTALL_DIR=~/Apps` | куда класть; по умолчанию `/Applications`, если он доступен на запись, иначе `~/Applications` |

### Вручную

Скачайте `Luna-<версия>-macos-universal.zip` со [страницы релиза](https://github.com/stepaKaziatko/luna-releases/releases/latest), распакуйте и перенесите `Luna.app` в «Программы». Сборка не нотаризована Apple, поэтому скачанную браузером копию macOS открыть не даст, пока с неё не снят карантин:

```sh
xattr -dr com.apple.quarantine /Applications/Luna.app
```

Скрипт установки делает это сам.

## Первый запуск

```sh
open /Applications/Luna.app
```

В строке меню появится значок луны, на экране — небольшой индикатор задач.

| Действие | Хоткей |
|---|---|
| Панель ввода | `⌥ Space` |
| Последний результат | `⌥ ⇧ Space` |
| Список задач | `⌥ ⌘ Space` |

Разрешения macOS Luna просит по мере надобности, а не при старте:

- **Автоматизация** — чтобы видеть адрес страницы в Safari и браузерах на Chromium. macOS спросит сама, когда вы впервые вызовете панель над браузером.
- **Универсальный доступ** — чтобы видеть выделенный текст. Выдаётся по кнопке «Выделение: дать доступ» в панели ввода.

Без разрешений Luna работает, просто знает о контексте меньше. После обновления macOS может спросить разрешения заново.

## Linux

Приложения под Linux пока нет. В релизе лежит `luna-core-<версия>-linux.tar.gz` — ядро без интерфейса: очередь задач и исполнители за JSON-RPC на stdio. Запускается через `node main.js`, нужен только Node.js 22.18+.

## Проверка файлов

К каждому релизу приложен `checksums.txt` с SHA-256 всех файлов:

```sh
shasum -a 256 -c checksums.txt --ignore-missing
```
