# Luna

Luna живёт в вырезе MacBook (на мониторе без выреза — в полоске у верхнего края) и присматривает за сессиями ИИ-агентов: Claude Code, Codex, Gemini CLI, Cursor, Copilot CLI, OpenCode, Amp, Hermes и других. Из острова можно разрешить или отклонить запрос агента, ответить на его вопрос, перейти к его терминалу, поговорить с моделью, бросить файл, следить за GitHub, Vercel, Stripe и другими сервисами — не отрываясь от работы. В острове — маленький персонаж, который дышит, моргает и следит за курсором.

В этом репозитории лежат готовые сборки. Исходный код закрыт.

## Что умеет

- **Сессии агентов в острове.** Каждая сессия — своя «таблетка» с аватаром: что агент читает, правит и запускает, шаг за шагом; правки файлов с `+N −M`, по клику — полный diff. Закончил — персонаж радуется.
- **Разрешения и вопросы.** Запросы агента на разрешение приходят в остров с кнопками Allow / Deny / Always, вопросы — с вариантами ответа. Ничего не разрешается без вашего клика.
- **Переход к терминалу** сессии одной командой.
- **Чат** с Claude, Gemini, OpenAI или локальной моделью (Ollama, LM Studio) по своему ключу; диктовка в чат; лимиты плана Claude и Codex в шапке.
- **Интеграции:** GitHub, Vercel, Stripe, Resend, n8n, Notion, Cal.com, Apple Music, Spotify, Apple Mail, курсы криптовалют.
- **Файл на остров** — персонаж «проглатывает» его, дальше вопрос по файлу или письмо.
- **«OK Luna»** — голосовое управление: речь распознаётся на Mac, в Anthropic уходит только текст.
- **Еженедельный отчёт** по понедельникам: время, сессии, файлы, строки, команды.

Интерфейс на десяти языках, без телеметрии, ключи хранятся в Keychain.

## Установка

Нужна macOS 15 или новее. Больше ничего ставить не требуется: Luna — одно приложение для Apple Silicon и Intel.

```sh
curl -fsSL https://raw.githubusercontent.com/stepaKaziatko/luna-releases/main/install.sh | sh
```

Скрипт качает последний релиз, сверяет контрольную сумму и кладёт `Luna.app` в «Программы». Этой же командой Luna обновляется.

| Переменная | Что делает |
|---|---|
| `LUNA_VERSION=v1.0.0` | поставить конкретный релиз вместо последнего |
| `LUNA_INSTALL_DIR=~/Apps` | куда класть; по умолчанию `/Applications`, если он доступен на запись, иначе `~/Applications` |

Версия 1.0.0 — другое приложение, а не обновление 0.7.x: задачи, историю и настройки прежних версий она не переносит и не удаляет.

### Что лежит в релизе

В каждом релизе два файла: `Luna-<версия>-macos-universal.zip` с `Luna.app` (arm64 и x86_64 в одном бандле) и `checksums.txt` с SHA-256. Ядра и сборок под другие системы нет.

### Вручную

Скачайте `Luna-<версия>-macos-universal.zip` со [страницы релиза](https://github.com/stepaKaziatko/luna-releases/releases/latest), распакуйте и перенесите `Luna.app` в «Программы». Сборка подписана ad-hoc и не нотаризована Apple, поэтому скачанную браузером копию macOS открыть не даст, пока с неё не снят карантин:

```sh
xattr -dr com.apple.quarantine /Applications/Luna.app
```

Скрипт установки делает это сам.

## Первый запуск

```sh
open /Applications/Luna.app
```

У верхнего края экрана появится остров — в вырезе MacBook или полоской по центру на мониторе без выреза; в строке меню — значок Luna с меню: открыть остров, настройки, выход.

Агенты подключаются хуками: Luna предлагает добавить свой хук в `~/.claude/settings.json` (и аналоги у других CLI) и показывает diff перед записью. Без вашего подтверждения файл не меняется.

### Хоткеи

Работают из любого приложения, меняются в настройках (раздел Shortcuts).

| Действие | Хоткей |
|---|---|
| Открыть чат | `⌃⌥Space` |
| К ожидающему запросу агента | `⌃⌥A` |
| К терминалу агента | `⌃⌥T` |
| Прикрепить переднее окно как контекст | `⌃⌥W` |
| Следующая / предыдущая таблетка | `⌃⌥]` / `⌃⌥[` |
| Включить / выключить звук | `⌃⌥M` |
| Персонаж на рабочий стол и обратно | `⌃⌥D` |
| Гардероб | `⌃⌥G` |

Ещё два сочетания по умолчанию выключены и включаются в настройках: `⌘⇧N` — открыть и закрыть остров, `⌃⌥V` — говорить с Luna без слова-активатора.

### Разрешения macOS

Luna просит их по мере надобности, а не при старте, и без них работает в урезанном виде. После обновления macOS может спросить разрешения заново.

| Разрешение | Зачем |
|---|---|
| Автоматизация | перейти к окну терминала, управлять Музыкой и Spotify, отправить письмо через Mail |
| Универсальный доступ | заголовок активного окна, когда его прикрепляют как контекст |
| Микрофон и распознавание речи | диктовка в чат и «OK Luna» |
| Контакты | адрес получателя, когда письмо просят голосом |

## Проверка файлов

К каждому релизу приложен `checksums.txt` с SHA-256 всех файлов:

```sh
shasum -a 256 -c checksums.txt --ignore-missing
```

Каждый выложенный релиз проверяет workflow «Verify release»: ставит сборку скриптом установки, сверяет подпись и архитектуры, запускает приложение и убеждается, что оно завершается по сигналу.
